# Native Windows hardware inventory
SetupAPI enumerates present USB device nodes with VID/PID. Configuration Manager reports started/problem state and SetupAPI reports manufacturer, friendly name and driver key presence. Composite interfaces may appear separately; vendor hints are not verified manufacturer or Android identity. All USB peripherals may appear, not just phones. WM_DEVICECHANGE arrival/removal or devnode change triggers a debounced inventory refresh while monitoring is enabled. Manual refresh also checks adb/fastboot version with a five-second timeout. No driver installation, USB claims, authorization changes or device writes. PATH executable trust remains a limitation. Native API behavior and physical hotplug require Windows hardware acceptance.
