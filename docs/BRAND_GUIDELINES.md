# Droid Lab visual identity
Obsidian #0B1119, slate #182433, emerald #00E5B0, blue #398CFF, off-white #F2F6FC. Hexagonal Android emblem, DROID LAB, ENGINEERED BY CODEPHREX, Beyond Device Management. Vector emblem in assets/branding and matching WPF paths. Orbitron and Inter are preferred when installed, with Segoe UI fallback; fonts are not bundled. Shared WPF resources style buttons, navigation, text inputs and checkboxes; combo boxes retain native rendering. Command Center shows actual discovery snapshot counts, not live telemetry; failures are explicit. Navigation search filters existing modules. Dark theme only in this sprint; visual and accessibility testing on Windows pending.
