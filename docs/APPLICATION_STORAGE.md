# Application Manager and File & Storage Lab
Discover and select an authorized ADB device. Filter package inventory by identifier; enter an exact package identifier for dumpsys metadata and permissions. Install a trusted local single APK only after confirmation; no replacement, downgrade or permission grant flags are supplied. Uninstall requires explicit confirmation and may erase app data. Shared storage listing accepts simple relative paths under /sdcard, excludes Android app storage, and rejects shell metacharacters and traversal. Pull a selected path to a newly created local staging directory; no remote deletion or overwrite operation is offered. Device-side symlinks and OEM storage restrictions are not independently verified; use trusted devices. Package metadata is raw OEM-dependent output. Physical validation remains pending.
