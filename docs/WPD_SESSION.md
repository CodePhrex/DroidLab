# Native WPD session prototype
Direct COM session opens a selected device identifier, enumerates immediate object IDs from a parent (DEVICE root), and opens WPD_RESOURCE_DEFAULT in read-only mode. Download delegates to VerifiedTransfer with caller-supplied expected size. This is an internal prototype, not connected to the graphical browser. Object metadata, protocol classification, read-only client access flags, UI authorization, progress and cancellation integration, COM ABI/runtime validation and hardware acceptance remain required. Cancellation is cooperative between reads; a blocked driver read cannot be interrupted by this implementation. No production readiness claim.
