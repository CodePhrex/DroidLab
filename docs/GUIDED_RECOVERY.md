# Guided recovery
Select an authorized online ADB device, choose reboot target, acknowledge backup risks and confirm. Guided workflow rechecks discovery, identity and reported charge (conservative 50% threshold), then requests reboot only. Bootloader transition is restricted to profiles suggesting Fastboot. Polling checks matching serial and expected mode; system reboot additionally requires observed absence or non-online state. A missed transition, changed serial, unsupported OEM mode or timeout is unverified, not proof of failure. JSON session export includes serial and outcome. No flashing, sideload, reset, unlocking or protected servicing. Backup acknowledgement is not proof of a backup. Existing basic reboot remains separate. Hardware testing pending.
