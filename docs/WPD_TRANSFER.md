# Native WPD and verified transfer foundation
Native IPortableDeviceManager COM enumeration count is separate from Shell browsing. WPD count does not establish MTP protocol classification. VerifiedTransfer accepts a readable stream and expected byte count, reports bytes, supports cooperative cancellation, writes a unique temporary file, checks size and reread SHA-256, then moves without overwrite. This is a stream-level integrity check, not a device-supplied hash. The existing Shell CopyHere path does not use this engine; native WPD object/resource stream integration and transfer UI remain pending. No claim of physical compatibility. Tests cover size, no overwrite and cancellation.
