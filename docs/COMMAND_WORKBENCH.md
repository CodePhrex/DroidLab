# ADB and Fastboot Workbench
Select the appropriate module, scan devices, select the workbench target, filter the command library and execute a fixed read-only command. ADB requires device state; Fastboot requires fastboot state and physical authorization by the operator. Commands recheck discovery and use explicit serial targeting, argument lists and 30-second execution timeout. Logcat requests up to 200 recent lines filtered to warning and higher; logs may contain private information. Session history records command ID, timestamp, target and success/failure, not raw output. No unrestricted shell, flashing, unlock or erase. OEM support varies; Fastboot reported secure state is not proof of lock status. Physical validation pending.
