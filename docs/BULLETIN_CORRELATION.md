# Android bulletin correlation\nImport a locally curated JSON array transcribed from official Android Security Bulletins (https://source.android.com/docs/security/bulletin). Each record has Cve, PatchLevel (YYYY-MM-01 or YYYY-MM-05), AndroidVersions (exact reported release strings), Source (official bulletin URL). Select an authorized ADB device, import the file, and review results. A listed version with an older reported patch is potential exposure; equal/newer patch is reported coverage, not proof of remediation. Unlisted versions, invalid dates and future bulletins are unknown. The importer validates structure and source URL shape, not authenticity or completeness. No automatic bulletin scraping, OEM-specific correlation, exploitation or hardware validation is included. Empty catalogs do not establish security. Test CVEs are synthetic fixtures.
