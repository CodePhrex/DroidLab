# Droid Lab RC1 quick start
Download DroidLab-release-candidate from a successful Windows CI run. Compare SHA-256 hashes with SHA256SUMS.txt; unsigned packages are not publisher-authenticated. Install the setup or extract the portable ZIP. Install trusted Android SDK Platform Tools separately and add them to PATH; install OEM drivers if needed. Enable USB debugging on an authorized device and approve its RSA prompt. Open Command Center, scan, select the correct device and use diagnostics. For backup, choose an accessible shared folder and local destination; verify manifest before staged restoration. Recovery and app changes require confirmation; use disposable test data. Firmware inspection is read-only; flashing is disabled. Security matches are potential findings, not confirmed exploits. Droid AI requires a separately running Ollama instance and reviewed evidence. Reports export JSON, CSV or HTML (browser print to PDF). Subscription is a preview, not live billing. Uninstall via Windows Apps; user data outside the install directory remains. See ACCEPTANCE_TESTS.md for validation and FINAL_VALIDATION.md for limitations.
