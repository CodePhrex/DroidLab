# Commercial foundation
Community free, Professional USD 19.99/month, Enterprise USD 49.99/month. Licensing defines feature policy and verifies RSA-PSS SHA-256 signed JSON payloads using a trusted issuer public key, minimum 2048 bits. Envelope contains base64 Payload and Signature; claims include LicenseId, Product (DroidLab), Edition (numeric enum), NotBefore and Expires. Invalid, expired or missing licenses fall back to Community. No issuer key or private key is shipped. Production requires a pinned public key, secure server-side signing, billing webhook verification, revocation and account binding. ISubscriptionProvider is an interface only; no checkout or charges. Desktop displays edition catalog and development preview status; existing features remain accessible until production issuer and enforcement are configured. Offline validation uses local clock and is not tamper-proof. No license persistence or activation service yet.
