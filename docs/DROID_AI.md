# Droid AI
Install Ollama separately, start its local service on 127.0.0.1:11434 and install a local model. Open Droid AI, discover models, select one, enter a question and optionally paste reviewed diagnostic output or logs. Confirm submission. The application uses only the loopback HTTP endpoint, disables proxies and redirects, and does not execute model output. Prefer offline models; Ollama configuration or cloud-backed models may transmit data externally, so verify provider behavior before sharing sensitive information. No automatic log collection, redaction, chat persistence or cloud provider integration. Prompt limits 4000/24000 characters, generation cap 1024 tokens and five-minute HTTP timeout. Model output is advisory and can be incorrect; prompt instructions are not a security guarantee. Live inference and hardware validation pending.
