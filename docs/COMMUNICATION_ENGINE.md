# Sprint 28 — communication engine foundation
The adapter contract currently supports ADB and Fastboot via existing platform tools. Sessions are keyed by transport and serial, not presumed physical identity. Successful scans report arrivals and departures; failed scans retain stale sessions without falsely reporting disconnects. Stale sessions are never included in the actionable device picker. Desktop automatic polling is opt-in, every 10 seconds, skips busy operations and stops when the window closes. Tool errors are reported in discovery results. This is platform-tool polling, not native USB hotplug or driver enumeration. No additional OEM protocol support, persistent sessions or automatic reconnect commands are claimed. Physical acceptance and richer USB/driver diagnostics remain pending.
