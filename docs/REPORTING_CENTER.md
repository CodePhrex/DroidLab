# Reporting Center
Select an authorized online ADB device and collect a fresh read-only snapshot. Identity, battery, storage and memory are collected separately; failed sections remain unavailable. Reports include selected identity fields, diagnostic findings and reported patch/boot assessment, not raw logs, serial, application inventory or confirmed CVEs. Export JSON, CSV or standalone HTML. HTML escapes device text; CSV quotes fields and neutralizes common spreadsheet formulas. Review before sharing. For PDF, open the HTML report in a browser and use Print to PDF; no native PDF generator is included. Recovery and technician history remain separate exports. Physical validation pending.
