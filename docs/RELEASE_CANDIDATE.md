# Droid Lab 1.0.0-rc.1
Windows x64 self-contained build; .NET runtime bundled. Inno Setup 6 creates a per-user installer with selectable directory, Start menu and optional desktop shortcut, and uninstall support. CI builds installer and portable ZIP, generates SHA256SUMS.txt, and checks silent install, process survival for eight seconds and uninstall. This is not UI acceptance or hardware validation. Download DroidLab-release-candidate from successful Windows CI artifacts. Verify with Get-FileHash .\\DroidLab-Setup-x64.exe -Algorithm SHA256 against SHA256SUMS.txt. Unsigned RC: do not treat checksum as publisher authentication; code signing and trusted distribution pending. ADB/Fastboot must be installed separately from trusted Android platform tools and available on PATH; OEM drivers not bundled. Uninstall preserves user data outside install directory. No public release automatically published. Build locally from repository root: dotnet publish src/DroidLab.Desktop -c Release -r win-x64 --self-contained true -o publish; then run installer/Package.ps1 with Inno Setup 6 installed. Physical Windows 10/11 and Android testing required.
