# Appearance and live output
Use the appearance selector or Ctrl+T to toggle light/dark. Preference is stored in LocalApplicationData/DroidLab/appearance.txt; missing, invalid or unreadable settings default to dark. Save errors are reported. Ctrl+F focuses module search; F6 focuses output. Detach opens one owned read-only window bound to the current output text, including subsequent updates and clears. It is not a shell, streaming subprocess terminal or historical log. Native Windows controls retain system styling where applicable. Keyboard shortcuts, accessible names and focus indicators are provided; screen-reader, contrast, DPI and high-contrast acceptance require physical testing.
