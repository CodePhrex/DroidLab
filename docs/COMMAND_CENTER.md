# Command Center cards and diagnostic snapshots
Discovery populates selectable cards with serial, transport, state and reported details. Only authorized online ADB cards enable diagnostic shortcuts. Selection is explicit; changing cards clears meters. Refresh reads battery, memory and /data storage independently, reports errors, and labels the device and snapshot time. Unknown values are hidden rather than shown as zero. The operation gate prevents overlapping participating device operations. No continuous telemetry, simulated readings or write operations. Physical UI acceptance remains pending.
