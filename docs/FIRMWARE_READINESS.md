# Firmware readiness
Select an authorized ADB device and local firmware package. Import a JSON object with Manufacturer, Model, Product, Sha256 and optional RollbackIndex (integer or null), obtained from trusted OEM documentation. The application compares reported device identity and computed SHA-256 with these declarations. Package classification is heuristic. The desktop does not obtain a trustworthy rollback index, so rollback remains unknown there. The engine supports comparison of externally supplied comparable indices for future OEM adapters. No signature, carrier variant, bootloader authorization or anti-rollback domain verification is performed. FlashApproved is always false. No device writes or archive extraction occur. Physical testing remains required.
